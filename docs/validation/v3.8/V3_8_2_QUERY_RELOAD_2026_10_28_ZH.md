## Host可行性与停止决议

OpenAI官方文档及本机生成schema含config/mcpServer/reload，参数无单服务选择。普通沙盒看不到端点；定向只读权限下发现两个候选，均未在8秒内返回initialize响应。未取得当前线程绑定，不发送重载，不终止任何Host／服务。探测器只结束自己创建的proxy子进程。不能归因于缓存、权限、启动顺序或协议绑定中的某一种。

只读探测退出0仅表示线程／服务目录绑定，明确client_readiness与restart_verified仍未验。没有把只读探测包装成已可用的自动重启脚本。按维护者批准的有限计划继续Query功能；有确认端点或新证据才重开Host诊断。DRR-146记录快照／在途限制，DRR-147保持开放。

## 冻结的重启原生验收

1. 当前Host重新发现reload_skills，核对无路径／SQL参数及管理注解；只读常量确认可调用。
2. 在已配置Skill根下创建本批独占的临时Query目录，仅SELECT常量；新增、发现、详情和执行完整通过。
3. 修改常量／参数后，发布前仍旧、显式重载后新版；同名Skill不需重建MCP工具集合。
4. 写入非法DML候选，重载结构化失败，已加载Query仍正常；不确认或执行任何写入。
5. 清理本批临时目录并重载，确认移除；不修改原有Skill／私有配置／grant。逐项保留失败，不补跑至通过。

原生阶段通过前不把DRR-146写成全部验收关闭；完整Luna任务另记实际工具可用性、模型／effort、调用、token及解释结果，不能从工程工作流推导收益。
