# v3.8.1 共享 CTE 结构分析修复与验收（2026-10-15）

本批按维护者授权修复前批 DRR-2026-098 的功能限制，同时检查相邻误拒和授权边界。**源码、安装包、真实 MySQL 及重启后的当前 Host 验收均完成，原生 20/20 通过。** 版本仍为 3.8.1，未创建 commit。前批诊断 10/10、1560 项回归和更早 Luna 任务均保留原源码归属，不冒充本批生产修复的原生／模型验收。

## 修复与原理

| 变更 | 原因／旧问题 | 解决原理及结果 | 好处与代价 |
| --- | --- | --- | --- |
| 共享 WITH 结构 | get_type() 依赖可选 Identifier 分组，data／summary／Unicode 等合法裸名会 UNKNOWN | 新增 core/structure.py，按原始叶子、括号和声明顺序提取 WithClause／CTEDefinition／SQLFragment；分类与关系分析使用同一接口 | 覆盖普通业务名及标准引用；新增少量内部结构和片段解析开销，无新依赖 |
| 列列表／物化／注释 | 引用名列列表使查询体嵌套；AS 注释和 MATERIALIZED 形态无法正确分类 | 明确识别名称、可选列列表、AS、可选物化提示和完整查询体。查询仍按原文交给适配器执行，不删提示、不改名称 | raw／Skill／readiness 对齐，假缺表依赖消除；不等同于完整方言语法验证 |
| 声明与真实调用／写入 | replace(n) 被视为 DML；扩大声明排除会隐藏体内函数 | 只排除原始声明名称／列列表的叶子。共享关系目标选择器识别 FROM／JOIN／逗号／IN 中的名称，写入与函数参数／查询体不整体排除 | 支持上下文关系名，仍逐体拒绝实际写入及保留调用；增加组合回归成本 |
| 运算符形名称 | like／regexp 的名称 token 被标为比较运算符，不能仅依赖类别 | 在已明确的名称／关系目标位置保留原始词形和结构化身份；名称本身不授予权限 | 关闭相邻既有误拒；权限仍由 RelationReference 与连接规则决定 |
| WHERE 分组边界 | sqlparse 可把 WHERE ... IN 与裸 unıon／lımıt 切开，找不到右侧操作数 | 共享 significant_sql_tokens 在当前查询块展开可选 WHERE 容器，保留外侧相邻操作数；嵌套表达式／子查询仍独立遍历 | 修复 raw 和 CTE 内的裸 IN，未授权物理表仍被拒绝；不按 Unicode 转换合并业务名称 |

生产改动只有 core/sql.py、core/policy.py 及新增 core/structure.py。既有词法选择器移入共享模块；schema/name、引号内容、ASCII 比较和连接实际 CTE 大小写规则保持。关系分析逐声明增加可见集合，非 RECURSIVE 的本名及后续名称不会提前豁免；限定物理引用始终保留。SQLite 前向／隐式递归的既有保守范围并未整体扩大。

已识别的主语句写入返回 read_only_required；读取体内真实写入返回 nested_write_denied。未完整识别的 WITH 返回 sql_parse_failed，提示同连接检查声明、括号和只读查询体；不能从 WITH 前缀推定安全。保留函数检查继续发生在连接能力探测、readiness 和业务数据库 I/O 之前。缓存 Skill 独立复验，不以启动检查替代运行检查。

## 成本与架构边界

在其他回归结束后，使用同样六条前后均允许的 SQL、两种策略，串行 A/B/A，每阶段 360 个纯策略采样，预热固定。median 为 **8.64／10.99／11.11 ms**，p95 为 **13.12／17.71／16.15 ms**。B 的 p95 高于两个对照，A 本身也有漂移；本次增加了结构／片段分析，**不宣称提速或无延迟代价**。这是本地纯策略观察，不是数据库、Host 或完整 Agent 延迟，也不是计费 token 测量。原始采样保留。

提示资源、工具 schema 和配置不变，不增加 Agent 必需步骤；成功返回替代原来的误拒会改变单次返回内容，不能由固定元数据不变推导总 token 不变。没有重测旧 Luna 任务的 token／账单。未来可在这一接口上逐步替换解析实现、减少重复解析；本轮没有生产 SQLGlot／authorizer、跨请求策略结果缓存或旧入口兼容层。SQLFragment 仅用于内部分析片段，不改写待执行 SQL。

共享结构接口仍是有边界的结构分析，不校验所有数据库语义，不保证任意复杂 SQL 都支持。保留函数政策、系统对象边界、单语句、禁用 UNION、FROM 子查询限制和实体授权仍独立生效。其他 MySQL 大小写配置、MariaDB 及更广 Host 未新增实测；连接的原有保守 fallback 保留。authorizer 的缓存／连接生命周期问题仍留后续生产接入设计。

资料核对：[sqlparse 定位](https://sqlparse.readthedocs.io/en/latest/intro.html)、[SQLite WITH／物化提示](https://www.sqlite.org/lang_with.html)、[MySQL CTE 作用域](https://dev.mysql.com/doc/refman/8.0/en/with.html)。官方说明用于核对接口与方言边界，具体修复结论来自本机 sqlparse 0.6.0／SQLite 及当前 MySQL 实测，不以在线开发版文档证明本机行为。
