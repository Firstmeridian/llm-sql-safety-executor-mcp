## 真值与评分方法

任务提示及判定在业务试验前写入[固定计划](real_tasks_2026_10_15/plan.json)，不向被测代理提供预期数字或推荐工具序列；主持者只按预设脚本发送当前轮请求，没有额外纠错。数字与调用轨迹分别核验，数字出现检查不能单独替代语义评审。最终答复、范围变化、索引建议来源、预览语义和纠错轨迹由主持者结合公开结果复核。方法参考 OpenAI 的[工作流轨迹验收](https://developers.openai.com/api/docs/guides/agent-evals)及[先定义结果、过程、效率标准](https://developers.openai.com/blog/eval-skills)，没有依赖外部评测平台或模型裁判。

独立真值使用 sqlite3 的 mode=ro、明确 main schema，以及配置 MySQL 适配器的 SELECT，不复用 Agent 的 SQL 作为唯一答案。[测试前快照](real_tasks_2026_10_15/truth_before.json)与[测试后快照](real_tasks_2026_10_15/truth_after.json)对照：7 张 SQLite 授权表全字段排序后的数据摘要不变，订单 4 仍 returned；MySQL 的订单总数及一月汇总不变。测试后增加错误连接算法的独立核对值，原测试前文件不改写。快照一致不能证明其他写入者在任意中间时刻没有活动；本轮轨迹另外确认没有 confirm=true 或实际写入调用。

不同连接的任务可并行，同一连接的独立试验依次进行，避免把并发冲突当成自然任务能力。试验仍共享服务进程、连接池、能力缓存和 Host 缓存，不声称服务状态彼此独立。元数据只证明其观察范围，估计行数不替代本次精确业务聚合。

## 观察到的偏差与建议

| 观察 | 实际影响 | 建议 |
| --- | --- | --- |
| 38 次本地工具目录检查，13 次目录输出被 Host 截断 | 模型重复取局部说明；这与数据库结果行截断不同，后者本轮没有发生 | 优先验证收窄工具发现范围、一次获得所选工具完整定义的 Host 配置；同条件对照后再决定产品提示是否需调整 |
| routing 2 把 category=query 当成 Skill 类型，两个连接各失败搜索两次；另有三次合法无匹配搜索，共 7 次空目录结果 | 最终通过完整目录恢复，但产生可避免的回合和上下文开销；“按状态汇总”无现成 Skill 的搜索不一概算错误 | 单独评估 category/type 区分及未知类别提示，按原任务做 A/B，先不增加泛化指令；不能把所有空搜索都等同功能失败 |
| 三次恢复任务都在第一轮额外预览 reset，第二轮又按明确请求重新预览 | 共三次提前的附加预览；均未写库，最后取消也未执行，但路径不是最精简 | 先发现并说明恢复方案，进入用户指定的预览阶段后生成该步预览；仍保留重新读取状态的必要调用 |
| 三次对账先观察到约 10^-13 的浮点尾差，再自行按金额精度复核 | 多一次查询；最终分精度金额、差异数和并列顺序正确 | 业务金额比较应明确精度；这是代理自行复核，不是产品报错或主持者纠错，不能删除首次结果 |
| routing 2、3 虽正确解释成功空集，却未充分使用已有 schema_ready=true 的存在性观察 | 结论方向正确，措辞偏保守；已有 readiness 证据不应被说成从未观察表存在性 | 答复区分“空集单独证明什么”和“连同已有 readiness 可以证明什么”，保留相应证据来源，不额外扩大连接范围 |

这些是 Agent／Host 在本次任务中的观察，不构成 SQL 策略失效或新的数据库修复结论。本轮没有据此修改生产代码或提示；新建议需要针对性验证，不能将 3/3 外推为所有模型、任务、措辞或 Host 的可靠性保证。

## 验收边界与后续

本轮覆盖完整只读业务与受约束写入预览，不能替代真实提交／回滚、并发写入冲突、令牌到期／重放、MRTR UI、网络故障及负载验收；没有执行写入的模型样本不能证明真实写入批准判断。现有财务夹具按分没有真实不平衡记录，不能由“零差异”报告推断代理必然能找出缺明细、错金额或缺失客户。主配置也没有特殊 sqliteXorders／限定名冲突夹具，这些仍使用此前同源码的隔离边界证据。

下一批建议先在隔离副本加入缺明细、金额错配、NULL／跨月／退款等有真值的异常，扩充口语变体和重复样本；如覆盖实际提交闭环，先准备明确的写入及清理方案并按维护者约定批准。成本优化应复用这些任务在相同 Host／工具范围下对照，不与历史 Copilot、CLI 或单工具测量直接合并。生产 AST／authorizer 等原有暂缓范围保持其原决议。
